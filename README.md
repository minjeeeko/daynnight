# 낮과밤 (Day & Night)

오프라인 만남 보장 매칭 플랫폼의 프론트엔드 목업 웹앱입니다.
채팅 없이 검증된 상대와 실제 오프라인 만남을 성사시키는 고관여 소개팅 경험을 구현했습니다.

## 실행

빌드 도구가 필요 없는 순수 HTML/CSS/JS입니다. `index.html`을 브라우저에서 열면 됩니다.

```bash
# 또는 간단한 로컬 서버로
python3 -m http.server 8080
# http://localhost:8080
```

## 화면 구성

- **탐색** — 신원·직장·학력이 검증된 상대 프로필 카탈로그, 좋아요/넘기기
- **매칭** — 상호 좋아요로 성사된 매칭 목록 (일정 입력 → 확정 대기 → 만남 확정 → 완료)
- **매칭 상세** — 진행 단계 스텝퍼, 가용 시간·선호 지역 입력(캘린더), 확정된 만남 안내, 50:50 정산 결과
- **만남** — 도착 인증(GPS/QR), 30분 타이머, 30분 후 지속 여부(Yes/No) 독립 선택, 자동 분할 정산
- **마이** — 4단계 검증 상태, 예치 보증금·위로금 크레딧, 결제·정산 내역

## 특징

- 반응형: 모바일(하단 탭바) → 태블릿(2열) → 데스크톱(사이드바 + 다열 그리드), 화면을 꽉 채움
- 디자인: Seed Design(당근) 토큰 기반 — Karrot Orange 액센트, 4px 그리드, 3단계 그림자
- 폰트: NanumBareunGothicOldHangeul (나눔바른고딕 옛한글)
- 모든 데이터는 `data.js`의 목업 데이터입니다.

## 파일

- `index.html` — 앱 셸 (사이드바 / 앱바 / 탭바)
- `styles.css` — 디자인 토큰 및 컴포넌트 스타일
- `app.js` — 라우팅, 화면 렌더링, 인터랙션
- `data.js` — 목업 데이터
